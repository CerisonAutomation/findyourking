DEPLOYMENT PROCEDURE
====================

1. Final systems check
2. Activate feature flag (if gradual rollout)
3. Deploy to 10% of users
4. Monitor for 30 minutes
5. If OK, deploy to 50%
6. Monitor for 1 hour
7. If OK, deploy to 100%
8. Monitor continuously for 24 hours
9. Maintain on-call rotation
10. Document lessons learned

ROLLBACK PROCEDURE
==================

If critical issue detected:
1. Immediately disable feature flag
2. Revert database migration (if needed)
3. Revert code to previous version
4. Restore from backup (if needed)
5. Notify all stakeholders
6. Post-mortem meeting
7. Fix issue
8. Return to Phase 0
