# ZENITH PROMPT SUITE - Legendary Development Standards

This directory contains the Zenith Prompt Suite—a comprehensive framework for legendary-tier software development.

## Overview

The Zenith Prompt Suite establishes elite development standards across four key dimensions:

1. **Zenith Superprompt** - Core development mandate
2. **Horus Omniscient** - Implementation excellence
3. **Oracle Verification** - Quality assurance
4. **Zenith Release** - Production certification

## Files

### `/prompts/zenith-superprompt.txt`
The foundational mandate that drives all development work.

**Key Principles:**
- Absorb complete context before implementation
- Use only verified, official documentation
- Deliver complete solutions, never partial
- Maintain legendary quality standards
- Never compromise on security, performance, or accessibility
- Refuse incomplete work

### `/prompts/horus-omniscient-autoperfect.txt`
The implementation agent that synthesizes optimal solutions.

**Key Capabilities:**
- Omniscient parsing of codebase and requirements
- Auto-synthesis of complete, optimal solutions
- Perpetual self-refinement toward perfection
- Auto-correction of gaps, bugs, and inefficiencies
- Documentation alignment with official standards

### `/prompts/oracle-doc-verification.txt`
The quality assurance auditor that certifies standards.

**Key Responsibilities:**
- Cross-reference all output against official documentation
- Comprehensive audit checklist (20+ categories)
- Security, performance, accessibility validation
- Generate detailed audit reports
- Refuse approval until standards met

### `/prompts/zenith-release-checklist.txt`
The production readiness certification process.

**Release Gates:**
- 13-phase validation process
- All-or-nothing release criteria
- Performance, security, accessibility benchmarks
- Staged rollout procedure
- Rollback procedure tested
- Success metrics defined

## Usage

### For Development Tasks

```bash
# Load the Zenith mandate before starting work
cat prompts/zenith-superprompt.txt

# Use HORUS protocol for implementation
cat prompts/horus-omniscient-autoperfect.txt

# Run ORACLE audit before review
cat prompts/oracle-doc-verification.txt

# Validate production readiness
cat prompts/zenith-release-checklist.txt
```

### For IDE/Editor Integration

#### Cursor
Add to `.cursorrules`:
```
Reference: prompts/zenith-superprompt.txt
Reference: prompts/horus-omniscient-autoperfect.txt
Reference: prompts/oracle-doc-verification.txt
```

#### Continue.dev
Add to `.continue/config.json`:
```json
{
  "systemPrompt": "You are HORUS and ORACLE. Reference prompts/zenith-superprompt.txt for mandate.",
  "contextLength": 10000
}
```

#### Manual LLM Calls
```
Include these files in the system prompt:
1. zenith-superprompt.txt (core mandate)
2. horus-omniscient-autoperfect.txt (for code tasks)
3. oracle-doc-verification.txt (for QA/review)
```

## Standards Summary

### Code Quality
- Type Safety: Strict mode, no implicit any
- Test Coverage: ≥ 90% unit tests
- Error Handling: Comprehensive, with logging
- Documentation: 100% of complex logic

### Security
- Input Validation: All boundaries
- Output Encoding: XSS prevention
- Authentication: Secure by default
- Rate Limiting: On all public APIs
- Secrets: Environment variables only

### Performance
- Lighthouse Score: ≥ 90
- First Contentful Paint: < 1s
- Database Queries: Optimized, indexed
- Bundle Size: Below targets
- API Response Times: < 200ms

### Accessibility
- WCAG 2.1 AA Compliant
- Semantic HTML Throughout
- Keyboard Navigation Full Support
- Screen Reader Compatible
- Color Contrast Sufficient

### Testing
- Unit Tests: ≥ 90% coverage

- E2E Tests: Critical user journeys
- Performance Tests: Load/stress
