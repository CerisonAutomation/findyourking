### 2. **Card Interactions** (Inspired by Apple)
**Current:** Scale on hover  
**Target:** 3D tilt + glow

```typescript
// Add 3D tilt on mouse move
const [rotateX, setRotateX] = useState(0);
const [rotateY, setRotateY] = useState(0);

<motion.div
  onMouseMove={(e) => {
    const rect = e.currentTarget.getBoundingClientRect();
    const x = (e.clientX - rect.left) / rect.width;
    const y = (e.clientY - rect.top) / rect.height;
    setRotateY((x - 0.5) * 20);
    setRotateX((y - 0.5) * -20);
  }}
  style={{
    rotateX,
    rotateY,
    transformStyle: "preserve-3d"
  }}
>
```

### 3. **Scroll Animations** (Inspired by Linear)
**Current:** Basic fade-in  
**Target:** Stagger + reveal

```typescript
// Stagger children on scroll into view
<motion.div
  initial="hidden"
  whileInView="visible"
  viewport={{ once: true, margin: "-100px" }}
  variants={{
    visible: {
      transition: {
        staggerChildren: 0.1
      }
    }
  }}
>
  {items.map((item) => (
    <motion.div
      variants={{
        hidden: { opacity: 0, y: 20 },
        visible: { opacity: 1, y: 0 }
      }}
    />
  ))}
</motion.div>
```
